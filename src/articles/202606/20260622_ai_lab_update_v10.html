久しぶりのLABレポートです。前回（第9回）は2026年6月3日。その後3週間で、AI開発ツール業界は想定外の出来事が連続しました。Fable 5の輸出規制停止・Windsurf消滅・OpenCode 160K Stars台頭——第10回はこの激動の3週間をまとめます。

🔥 6月前半の3大ショック

🚨 ① Fable 5 & Mythos 5 全世界アクセス停止（6月12日）

米国政府が国家安全保障を根拠に輸出規制指令を発出。Anthropicは全ユーザーのアクセスを一夜で無効化しました。引き金はFable 5のジェイルブレイク手法の発見でしたが、Anthropicは「商用モデルをジェイルブレイク1件で停止するのは過剰」と公式に反論。それでも命令には従わざるを得ませんでした。

Claude Code / Sonnet 4.6 / Opus 4.8 は影響なし。ただしこの出来事は「AIモデルはいつ突然使えなくなるかわからない」という現実を業界全体に突きつけました。

🦾 ② Windsurf → Devin Desktop 消滅（6月2日）

Cognitionが2025年12月に約$250Mで買収したWindsurfを正式に「Devin Desktop」へリブランド。起動画面が「コードエディタ」から「Agent Command Center」へ反転。旧ローカルエージェントCascadeは7月1日にEOLとなり、Rustで完全再実装した「Devin Local」（トークン効率30%向上）へ移行します。

🚀 ③ OpenCode 160K Stars突破（OSS最多）

モデル非依存のCLIファーストエージェント「OpenCode」が160K Starsを突破し、7.5M月間アクティブ開発者を獲得。75+プロバイダー対応・MIT・エアギャップ対応で「どのモデルが停止されても動き続ける」設計が評価されています。

🔑 第10回の4断層

  • 規制断層: 「政府命令で翌朝モデルが使えない」が初めてリアルに。規制リスク評価がAIアーキテクチャ設計の前提条件に
  • 設計断層: コードエディタ中心からエージェントコマンドセンター中心へ。UI/UXの主役交代が完了
  • 依存断層: OpenCode 160K Starsが示す「ベンダーロックイン拒絶」の大衆化。OSSは「お金を節約する手段」から「リスクを回避する戦略」へ昇格
  • 課金断層: 定額の時代が完全終了。エージェントが「100ツール呼び出し × 大コンテキスト」を生成する以上、定額では採算が合わない

🎯 第10回の結論

  • 当面の推奨体制: Claude Code（日常開発）+ OpenCode / LLM AI Router（フォールバック）の二本立てが最もリスク分散できる
  • Fable 5停止の教訓: 「最強モデル一本依存」は規制リスクを無視したギャンブル。マルチプロバイダー冗長設計が必須
  • Devin Desktopの示唆: 「エージェントが主役、エディタは脇役」という製品設計が業界標準になる。この流れを前提に開発環境を見直す時期
  • OpenCodeの意味: OSSが「安いだけの選択肢」から「戦略的な保険」へと昇格。中上級者にはBYOK型OSSが最合理な選択肢
