    この対局について

    • 駒を押すと動ける升が光ります。光った升を押すと指します。持ち駒は下の駒台から押して打ちます。
    • 強さは、CPU が 1 手に読む量と、わざと甘い手を混ぜる度合いで 5 段階にしています。段階の差は CPU 同士の対局で測りました。
    • CPU は考え始めると途中で止められません。考えている間に「待った」を押すと、CPU を読み込み直します。
    • 対局エンジン: やねうら王（WebAssembly 版は shielune/YaneuraOu v9.61.7）。評価関数: 水匠ぺてぃと（たややん氏、配布元）。どちらも GNU GPL v3 で、このページのソースは GitHub で公開しています。
